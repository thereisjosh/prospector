# 3-minute demo script

**Setup:** run `npm install && DEMO_MODE=1 npm run dev` and open `http://localhost:3000` in a fresh browser profile. Demo mode replays a live run recorded on 2026-11-21 (`eval/demo/run/events.jsonl` and `state.json`; run id `37c59dac-a58c-49eb-9a36-96da071328f2`): `eval/run-agent.ts --plan` on the demo plan with buyer roles "VP of Operations" and "Warehouse general manager", Sonnet 5.5, a $1.00 cap, target 10 leads, in a fresh workspace with no memory. It used 19 steps and $0.86 ($0.29 AI + $0.57 web), found 5 leads and stopped when the agent called finish. Each lead has a "Who to reach" line: 10 verified people (each on a company page or a news article, checked against the source page) and 2 inferred ones at RGL Logistics; the lookup for Hollingsworth Logistics found no one. The replay pauses at its strategy approval. In a second tab, open the README at [§1 Results](../README.md#1-results).

**No time to present live?** `docs/screenshots/walkthrough.gif` (41 s, 1280 px, recorded 2026-10-16 by `node scripts/demo-gif.mjs` on the pop.site-based visual system in [DESIGN.md](../DESIGN.md)) is the earlier script without the voice-over. It was recorded from the previous recording (8 leads, memory recall, no contacts), so its run and results screens do not match this script; re-record it with `node scripts/demo-gif.mjs` before using it.

**Know before you present:**
- Event costs sum to the run's spend, so the meter never overshoots. The five contact lookups cost $0.028 each, inside the $0.57 of web spend.
- In the recording, the strategy was auto-approved by the harness; in the replay, you press Approve.
- The recorded run had no scope-change request, so the scope-change card can't be shown in demo mode.
- The run wrote no checklist, so the checklist panel stays empty ("No checklist was written."). That is the recording, not a bug.
- Memory recall is not part of this recording. The run started in an empty workspace, so step 1 reads "Recalled memory: 0 companies already seen", nothing is skipped as seen, and the contract screen has no "already remembers N companies" line. After the replay, the run's own note ("New-facility press-release searches for 3PLs work; many hits are under 100 staff or flagged enterprise…") and its 5 leads and 2 turn-downs are written to the workspace, so "What I remember" shows them. The previous recording (memory-eval 2026-10-15b S1 rep 2, which recalled 7 companies) is pinned as a fixture in `eval/memory.test.ts`.
- Contacts appear on a lead row after the agent's contact lookups (step 16), not when the lead is accepted. Mid-run, a lead has no "Who to reach" line yet; that is the order the agent did it in. The verified contacts were checked by hand against their pages; the share of verified contacts that are right is not measured (README flaw 20).
- The leads of this run were not judged, and the run is not in the README §1 tables.

**If there's time for one question:** "What did the agent not do?" It submitted FreezPak Logistics twice and both were rejected (the decisive answer quote, then the signal quote, were not on the pages), so it dropped the company instead of delivering it unverified. And it stopped at 5 leads with $0.14 of the cap unspent because most of the candidates it found were under 100 staff or enterprise-scale; the contract's size range is what limited the count here.
