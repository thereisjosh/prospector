# 3-minute demo script

**Setup:** run `npm install && DEMO_MODE=1 npm run dev` and open `http://localhost:3000` in a fresh browser profile. Demo mode replays a live run recorded on 2026-11-21 (`eval/demo/run/events.jsonl` and `state.json`; run id `f19e666c-ad27-4e03-bdd3-19de2aea6363`): `eval/run-agent.ts --plan` on the demo plan with buyer roles "VP of Operations" and "Warehouse general manager", company size 50–1,000 employees, Sonnet 5.5, a $1.00 cap, target 10 leads, in a fresh workspace with no memory. It used 20 steps and $0.90 ($0.31 AI + $0.60 web; the app's meter adds the two rounded parts and shows $0.91), found 8 leads and stopped on the budget. Every lead was looked up for people to reach: 11 verified people (each on a company page or a news article, checked against the source page by hand on 2026-11-21) at J&J Global Fulfilment (3), G10 Fulfillment (3), Wagner Logistics (2) and Spartan Logistics (3); 5 inferred ones (a profile and nothing on a page) at Jay Group (3), Wagner Logistics (1) and Legacy Supply Chain (1); the lookups for Porter Logistics and Hollingsworth Logistics found no one. The replay pauses at its strategy approval. In a second tab, open the README at [§1 Results](../README.md#1-results).

**No time to present live?** `docs/screenshots/walkthrough.gif` (41 s, 1280 px, recorded 2026-10-16 by `node scripts/demo-gif.mjs` on the pop.site-based visual system in [DESIGN.md](../DESIGN.md)) is the earlier script without the voice-over. It was recorded from an earlier recording (8 leads, memory recall, no contacts), so its run and results screens do not match this script; re-record it with `node scripts/demo-gif.mjs` before using it.

**Know before you present:**
- Event costs sum to the run's spend, so the meter never overshoots. The eight contact lookups cost $0.028 each ($0.224), inside the $0.60 of web spend.
- In the recording, the strategy was auto-approved by the harness; in the replay, you press Approve.
- The recorded run had no scope-change request, so the scope-change card can't be shown in demo mode.
- The run wrote no checklist, so the checklist panel stays empty ("No checklist was written."). That is the recording, not a bug.
- Memory recall is not part of this recording. The run started in an empty workspace, so step 1 reads "Recalled memory: 0 companies already seen", nothing is skipped as seen, and the contract screen has no "already remembers N companies" line. The agent saved no note (its finish was held once to offer one, and the budget stop came first), so after the replay "What I remember" shows the run's 8 leads and its turn-downs, nothing under "What the agent learned", and the line "No note this time; the run stopped at its budget before the agent could save one." The memory-eval run of 2026-10-15 (S1 rep 2, which recalled 7 companies) is pinned as a fixture in `eval/memory.test.ts`.
- Contacts appear on a lead row after the agent's contact lookups (steps 6, 7, 9, 18 and 20), not when the lead is accepted. Mid-run, a lead has no "Who to reach" line yet; that is the order the agent did it in. Spartan Logistics' lookup is the last step, after the agent's finish was held once. The verified contacts were checked by hand against their pages; the share of verified contacts that are right is not measured (README flaw 20).
- The agent wrote its handback shortfall as "2 of 10" (the leads missing); the replay rewrites it to the leads found, so the screen says "Found 8 of the 10 leads you asked for". The handback has one piece of advice and no plan change to apply: "Budget ran out; the supply of mid-sized 3PL events is thin, but a bigger budget would likely find the last two." Its reasons are model-worded: under 50 employees (7), event date could not be confirmed on the page (3), too big or enterprise (3), event older than 3 months (2).
- The leads of this run were not judged, and the run is not in the README §1 tables.
