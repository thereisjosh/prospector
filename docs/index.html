Prospector

A natural-language prospecting agent built on the Exa Search API. It finds companies by a fresh, cited “why-now” trigger — a new facility, a funding round, a hiring wave — using a signal-first pipeline (date-filtered signal search → company enrichment → fit-gated scoring).

Where this fits at Exa — a working proof of the Sales / Enrichment category, the same web-sourced trigger prospecting Exa's own customers use:
